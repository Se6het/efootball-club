# efootball-league

一个可直接部署到 GitHub Pages 的中文足球联赛管理网页（俱乐部版）。

> 在线预览：https://se6het.github.io/efootball-club/

## 功能

- 左右两侧分别配置玩家 A、玩家 B
- 每个玩家选择 `x` 支俱乐部
- 内置 130+ 支俱乐部（含队徽与主题配色，覆盖五大联赛与中超），输入中文全称、简称或常用昵称都会自动匹配；也可直接填写自定义球队名
- 每对球队之间进行 `y` 场比赛，`y` 必须为偶数
- 记录比分、进球球员、助攻球员以及红黄牌球员
- 三张黄牌停赛一场，一张红牌停赛一场，下一场比赛会显示停赛提醒
- 赛程按半程随机分布；每个半程结束时所有球队已进行的比赛场次相同，单轮允许球队轮空
- 积分榜支持按任意维度排序；同分球队旁可一键展开「相互战绩小表」，直接看清同分时谁凭什么排在前面
- 新闻页自动生成看点与纪录（连续进球、球员陷入进球荒 / 参与进球荒、射手/助攻领跑、连胜与不败/不胜走势、零封、历史交锋压制、最大分差、攻防最佳、单场爆发、最火爆的比赛、比分复读机、0:0 专业户、MVP 包场等），只留最近几轮的「新鲜事」（整版上限 20 条），按稀有度上色并标出相关球队队徽
- 新闻页附带实时赔率：蒙特卡洛模拟算出各队夺冠、进前三赔率，以及球员金靴、助攻王、FMVP 赔率（赛季未结束时概率会向均势收缩，不会轻易给出 1.01；球队强度按「赛季表现 7 : 近期状态 3」加权，避免一场爆发把赔率拉飞）
- 「足球世界 · 档案」是独立入口：初始页有一整块大卡，联赛页有一条醒目横幅，不再挤在右上角小按钮里
- 「足球世界 · 档案」把一档成绩收进跨赛季的世界：本赛季随时归档或更新归档，世界里的每个档可单独导出 / 移除，也可整体导出 / 导入
- 每个赛季都完整留档：冠军、亚军、季军、金靴、助攻王、FMVP，总进球 / 场均进球，以及整张积分榜（名次、球队、教练、场胜平负、进失球、净胜球、积分，不只前三）
- 档案按教练记录：荣誉只算冠亚季——每个冠军单独成行、金框加重，亚军季军收成一行次要信息；另有胜平负比例、场均积分 / 场均进失球 / 净胜球 / 夺冠率、每季履历（带过哪些队、名次、是否夺冠）、执教过的球队一览表（一支一行：带过哪些届、共几届、拿过哪些荣誉）、无冠赛季数，以及教练之间的交手战绩（多少场多少胜、进失球、从未交手过的对手）；教练卡按冠军数排序，点开才展开细节
- 「世界之最」汇总夺冠最多、胜率之王、火力最猛、防守最稳、最大屠杀、最惨失利、宿敌、全面压制、垫底常客、世界总进球等纪录
- 数据保存到浏览器 `localStorage`

## 开发

```bash
npm install
npm test
```

## GitHub Pages

仓库根目录可直接作为 Pages 源，不需要构建步骤。
在 GitHub 仓库设置里把 Pages 来源指向 `main` 分支的 `/ (root)`。
